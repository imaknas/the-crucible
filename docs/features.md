# Features in detail

| Feature | What it does |
|---|---|
| **🌳 Conversation trees** | Every message is a checkpoint. Branch from any node, edit a question and re-ask it, and navigate the whole tree on a React Flow canvas. |
| **⚔️ Arena** | Send one prompt to several models. Each answers in parallel on its own branch of the tree, for side-by-side comparison. Models get no system prompt from the app, so you compare them as they ship; set your own in **Control Panel → System prompt** and every model (and debate participant) gets it. |
| **🗣️ Debate** | An argument explorer: two or more models argue over several rounds so you can see the strongest arguments and where they disagree. Round 1 is each model's independent answer; from then on each reads the others' previous answers, labelled *Participant A, B…* rather than by model name (so no model defers to a brand). The synthesis is an argument map — positions, their best arguments and evidence, who changed position and why, what is unresolved — not a verdict. Agreement reached by debating isn't evidence: for an answer to rely on, use Arena's independent answers and Synthesis. Stop early once answers stop changing or a judge finds the models now agree, pause between rounds, add a note mid-debate, or change the topic. |
| **📊 Per-answer metrics** | Every answer shows its time to first token, total time, input, output and reasoning tokens and its cost, priced on the day it was written ("price unknown" rather than a guess for a model without a price); a multi-model turn shows its total. |
| **➕ Add a model** | Ask one more model a turn that has already been answered: its answer joins that turn's cards, and what the next message continues doesn't move. |
| **🔍 Diff two answers** | "Compare with…" on any finished answer shows what differs from another, sentence by sentence for prose and line by line for code, words struck and underlined within a changed sentence. The debate shows each participant's first and last answer the same way. |
| **🗳️ Blind votes and win rates** | Vote on a turn's best answer (or a tie, or all bad) with the kind of task and a reason; with *Blind comparison* on, answers are lettered and unnamed until you vote. Win rates per model by task are in the Control Panel. |
| **💾 Saved cases and replay** | Save a turn as a case (its question, the history before it, documents, settings, answers and vote) and replay it on other models later; each new answer shows its cost and its diff against the old one. |
| **🧑‍⚖️ Peer review** | Each model that answered scores the others' answers from 1 to 10 with a reason, anonymously and never its own: evidence to weigh, not a verdict. |
| **🎭 Assigned sides** | In a debate, give each participant a side to argue whatever it thinks, or make one a devil's advocate against what the others agree on; the argument map is told who was assigned what. |
| **🧭 Moving around a big tree** | Arrow keys move through the tree without changing anything; name and bookmark branches, fold them, show one branch alone, or compress a branch into a summary written onto its node. Select text in a reply to branch from exactly that claim. |
| **👁️ Visible context** | A reply written from a summary, or with original messages brought back, says so and lists them; the composer says how many messages and roughly how many tokens the next turn sends each model, and "Start fresh" sends none. |
| **🔌 Runs outlive the tab** | Answers and debates run on the server: reload, close the tab or open a second one, and it catches up with what was written so far. Stop from any tab stops the run. |
| **⚖️ Deliberation** | Ask a model to critically review the thread so far, with every earlier message attributed to the model that wrote it. |
| **🤝 Synthesis** | Combine answers into one, stating where the models agree and where they don't; or build a table of where they differ, keep only the parts you tick, or ask a question about them. Pick answers from anywhere in the tree (Shift/Cmd-click) to combine them. |
| **📎 Documents & RAG** | Attach PDF, TXT, Markdown or CSV files (up to 10 MB). With *Search my documents* on, relevant passages are retrieved and graded before the model answers, with citations. |
| **🌐 Web search** | Let models that support it use their provider's native web-search tool. |
| **🧠 Context management** | When a thread outgrows a model's budget, older history is summarized (keeping who said what) instead of being cut off — and the summary is never the only copy: for each new question a small model picks which original messages it is about and shows them again. Choose the summarizer in **Control Panel → Summarizer**, or leave it on Automatic. |
| **🔬 Compaction research tools** | Measure what summarization loses on your own models (`crucible compaction-eval`), and re-check that every piece of context machinery still beats going without it whenever models change (`crucible scaffold-audit`). See [Research](../README.md#-research-what-survives-compaction). |
| **📐 LaTeX** | `$inline$` and `$$block$$` math rendered with KaTeX. |
| **⌨️ CLI & 🤖 MCP** | Everything the web UI does to a conversation — arenas, debates, syntheses, branching, search, uploads — from the terminal or from another agent, against the same database as the web UI. |
